# React API PostgreSQL feasibility

Khoa implemented the task #7 feasibility spike and ran it locally in VSC. The demonstrated scope is reading, updating and reading back a sample court price through React, Express and PostgreSQL.

The implementation and run instructions remain in [PR #36](https://github.com/buikhoa130406/se-project-t04/pull/36), branch `spike/khoa-react-api-postgres`, at `src/spikes/react-api-postgres/`. Check out that branch to run the spike. Its source is not included in the PA3 submission branch.

This result supports connectivity feasibility only. It does not establish booking concurrency correctness, five-second release performance, load capacity or production readiness. These limits also appear in the PA3 ADRs and data-validation scope.
